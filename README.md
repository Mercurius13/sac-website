# SAC SITE

The website for Student Activities Council, containing information about with upcoming (and past) events, information about the members and request form to borrow equipment.

Site is live on [sac-njit.onrender.com](https://sac.onrender.com)

Admins are allowed to login with a super secret password. They can edit the text, images and update the events.

Admin dashboard: [sac-njit-admin.onrender.com](https://sac-admin.onrender.com)

Don't forget to publish the changes you make.
